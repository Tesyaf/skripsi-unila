# Skills Skripsi UNILA

Kumpulan skill untuk membantu penulisan, revisi, audit referensi, metodologi komputasional, dan format LaTeX skripsi sesuai Panduan Penulisan Karya Ilmiah Universitas Lampung.

## Skill

- `skripsi-unila-penulisan`: struktur dan gaya penulisan skripsi.
- `skripsi-revisi-dosen`: mengubah catatan pembimbing menjadi daftar tindakan.
- `skripsi-bahasa-natural`: parafrasa berbasis gagasan penulis tanpa gaya AI generik.
- `skripsi-audit-referensi`: audit sitasi dan metadata daftar pustaka.
- `skripsi-metodologi-komputasional`: menyusun Bab III penelitian algoritma dan eksperimen.
- `skripsi-audit-format-latex`: audit dan kompilasi format LaTeX UNILA.

Skill ini berisi workflow umum. Sesuaikan nama fakultas, program studi, dataset, algoritma, dan aturan tambahan dari pembimbing.
